# SmartQueue — 5-minute demo script

## 0:00–0:40 — Problem
“During peak campus hours, students cannot see the real queue before physically waiting. Staff also lack a live view of congestion and service performance.”

## 0:40–1:20 — Student experience
“SmartQueue gives each student a digital token, live position and estimated waiting time. The student can leave the queue without standing in a physical line.”

## 1:20–2:10 — Operations
“On the admin side, the system shows the live queue, active counters and the student being served. FIFO selection keeps service order predictable.”

## 2:10–3:00 — Intelligence
“The system combines queue length, active counters and recent service duration to estimate waiting time and classify congestion. It also provides an operational recommendation such as opening another counter when pressure rises.”

## 3:00–4:00 — Analytics
“The dashboard records queue events and service records. This allows us to inspect demand and service completion trends rather than only looking at the current queue.”

## 4:00–5:00 — Why it can scale
“The same architecture can support canteens, libraries, clinics, help desks and other campus services. The frontend is React, the backend is Flask, and the data layer is SQLite for the prototype with a clear path to a production database.”
